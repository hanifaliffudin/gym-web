# Gym website project guidance

Read `DESIGN.md` before changing the interface. Apply the antislop core and UI rules to every UI change.

## antislop

For UI, copy, people, mobile layout, or code comments work, read `antislop.md` (core) and then the skill for the task:
- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`

Use the resolved antislop session mode while planning and implementing UI. Every visual technique needs a stated purpose, every interactive element needs real behavior, and the Delivery Gate must be completed before delivery.
